# دیپلوی روی لیارا — راهنمای گام‌به‌گام

این سند برای استقرار **سیستم معاملهٔ آزمایشی** (داشبورد + چرخهٔ روزانه) روی لیارا است.
معاملهٔ واقعی در این دیپلوی وجود ندارد — نردبان قفل است.

## معماری دیپلوی

```
Image (Docker)
 ├─ کد + وابستگی‌ها + دادهٔ بذر (۹MB کندل، بدون ۱دقیقه‌ای)
 ├─ uvicorn روی 0.0.0.0:$PORT (داشبورد)
 └─ MARKETMIND_SCHEDULER=1 → ترد داخلی: هر روز ۰۱:۰۰ UTC (۰۴:۳۰ تهران) چرخهٔ paper
Disk دائمی لیارا → /app/data
 ├─ paper.sqlite (حساب، موقعیت‌ها، تصمیم‌ها، نظرهای AI)
 ├─ candles/ (به‌روز می‌شود)
 └─ secrets/ (llm_api.json و dashboard_token.txt و telegram.json — از کنسول فایل‌منیجر لیارا)
```

نکته‌های مهم:
- **دیسک دائمی الزامی است** (`marketmind-data` روی `/app/data`) — بدون آن هر ریدپلوی داده‌ها را صفر می‌کند.
- **بذر داده**: اولین بوت، کندل‌ها را از `/app/deploy/seed` به `/app/data` کپی می‌کند؛ چرخهٔ بعدی از API تازه‌اش می‌کند.
- **توکن داشبورد الزامی است** چون URL عمومی است: `data/secrets/dashboard_token.txt` روی دیسک ساخته شود و لینک با `?token=...` باز شود.
- **پلن:** حداقل 512MB رم؛ پیشنهادی 1GB (pandas/pyarrow). پروژهٔ CPU-سبک است.
- **تلگرام از IP ایران:** api.telegram.org ممکن است مسدود باشد → یا بدون تلگرام اجرا شود، یا در `telegram.json` فیلد `base_url` به یک پروکسی ست شود. (والکس و LLM شما از ایران در دسترس‌اند.)
- اسرار **هرگز در ایمیج/گیت نیستند** — فقط روی دیسک.

## مراحل (وقتی توکن API لیارا آماده بود)

```bash
# ۰) نصب CLI لیارا (یک بار)
npm install -g @liara/cli   # یا: curl -fsSL https://cli.liara.ir | bash

# ۱) لاگین با توکن (توکن را جایگزین کنید)
liara login --token LIARA_API_TOKEN

# ۲) ساخت دیسک دائمی (یک بار)
liara disk create --name marketmind-data --size 1 # گیگابایت

# ۳) دیپلوی از ریشهٔ پروژه (liara.yaml تنظیم است)
liara deploy --app marketmind --image marketmind --docker ./deploy/Dockerfile

# ۴) پس از بالا آمدن: دو فایل راز را با فایل‌منیجر کنسول لیارا در /app/data/secrets/ بگذارید:
#    - llm_api.json   (همان که لوکال دارید)
#    - dashboard_token.txt  (یک رمز ۱۶+ کاراکتری)
#    - telegram.json  (اختیاری؛ اگر از IP ایران است، base_url پروکسی)
#    سپد یک ری‌استارت: liara restart --app marketmind

# ۵) باز کردن داشبورد
#    https://marketmind.REGION.liara.space/?token=رمزِ-شما
```

## به‌روزرسانی‌های بعدی
```bash
git pull && liara deploy --app marketmind ...
```
داده‌ها و حساب روی دیسک می‌مانند؛ ایمیج جدید فقط کد را عوض می‌کند و بوت بعدی اگر داده بود، بذر را رد می‌کند.

## عیب‌یابی سریع
| نشانه | علت احتمالی | راه‌حل |
|---|---|---|
| 401 روی `/` | توکن در URL نیست/غلط است | `?token=...` با محتوای فایل دیسک |
| داده‌ها بعد از ریدپلوی خالی | دیسک ماونت نشده | liara.yaml → disks → mountTo /app/data |
| AI همیشه «تحلیل ناموفق» | llm_api.json روی دیسک نیست/شبکه | فایل را بگذارید + ری‌استارت |
| چرخه روزانه اجرا نمی‌شود | MARKETMIND_SCHEDULER حذف شده | در Dockerfile بماند؛ لاگ اپ را ببینید |
| تلگرام ارسال نمی‌شود | بلاک از IP ایران | base_url پروکسی یا صرف‌نظر |

## لَایهٔ امنیتی
- داشبورد فقط با توکن در دسترس است؛ بدون توکن فقط لوکال.
- اسرار فقط روی دیسک؛ هیچ کلیدی در گیت/ایمیج/چت.
- این دیپلوی **فقط paper** است؛ کلید والکس و ماژول معاملهٔ واقعی طبق نردبان جدا مدیریت می‌شوند.
