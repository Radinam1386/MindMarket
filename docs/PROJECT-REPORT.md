## ۱. پروژه در یک پاراگراف

سیستم معامله‌گری خودکار برای بازار **تعهدی والکس** که با دیتای لایو کار می‌کند، تصمیم‌هایش را ترکیبی می‌گیرد (قوانین ریاضی قطعی + تحلیلگر هوش مصنوعی)، فعلاً با پول فرضی ۲۰۰ دلاری معامله می‌کند و همه‌چیز را ثبت می‌کند — تا بعد از اثبات عملی، با تأیید صریح مالک، به پول واقعی برسد.

## ۲. چه کارهایی انجام شد (به ترتیب زمانی)

### فاز ۰ — تحقیق و برنامه‌ریزی
- بررسی کامل مستندات رسمی والکس + پروب زندهٔ API → سند برنامهٔ ۲۵ بخشی (`MARKETMIND-PLAN.md`)
- تأیید محصول تعهدی: اهرم ۱–۱۰X (گام ۰/۵)، لانگ و شورت، کارمزد فعال‌سازی + تمدید ۴ساعته، سقف عمر ۲۱ روز، قیمت هشدار و لیکویید

### فاز ۱ — زیرساخت داده (T01–T07)
| قطعه | جزئیات |
|---|---|
| کلاینت والکس | محترم (۱ req/s)، retry با backoff، تست‌شده |
| دانلود تاریخچه | **~۲/۷ میلیون کندل**: ۹ دارایی USDT + USDTTMN؛ دقیقه‌ای از ۲۰۲۲ (کشف: پارامتر «۱۵» سرور واقعاً کندل ۱ دقیقه‌ای می‌دهد!)، ساعتی/۴ساعته/روزانه از ۲۰۱۹ |
| کشف فنی مهم | API فقط «۸۰۰ کندل آخرِ هر پنجره» می‌دهد → صفحه‌بندی معکوس پیاده شد |
| ممیزی کیفیت | نمرهٔ DQ برای هر سری؛ همه بالای ۰/۹۰ به‌جز ساعتی USDTTMN (۰/۸۹۹) |
| موتور بک‌تست | ضد-توهم داخلی: سیگنال در بستهٔ کندل، اجرا در open بعدی؛ تست واحد برای هر قاعده |

### فاز ۲ — حل مجهولات با endpointهای عمومی (کشف بزرگ)
Endpointهای مارجین والکس زیر `/margin-trade/v1/public/...` **بدون احراز هویت** کار می‌کنند:
- **اقتصاد واقعی اندازه‌گیری شد:** کارمزد معامله ۰/۲۵٪ فقط از وام در هر پا؛ فعال‌سازی و تمدید هر دو = وام÷۶۰۰۰ (تمدید هر ۴ ساعت فقط ~۰/۰۱۷٪ وام) — چند برابر ارزان‌تر از بدبینانه‌ترین فرض
- **فرمول لیکویید:** حرکت مخالف مجاز = ۰/۸۵۴۶ ÷ اهرم − ۰/۰۰۴۵ (در ۴ سطح اهرم دقیق فیت شد)
- **سقف موقعیت:** ارزش اسمی ۱۰۰ تا ۱۷۰۰ دلار (مستقل از اهرم)؛ ۳۵ بازار فعال تعهدی

### فاز ۳ — ۱۶ آزمایش پژوهشی (E001–E016)
| آزمایش | سؤال | نتیجه |
|---|---|---|
| E001 | آیا ترند‌فالوینگ خام سود می‌دهد؟ | بله قبل از هزینه: +۱۲۱۲٪ در ۷ سال |
| E002/E003 | آیا زیر کارمزد فرضی بدبینانه زنده می‌ماند؟ | **مرد** — کارمزد ساعت‌شارژ قاتل است |
| E005 | با کارمزد واقعی چی؟ | اهرم ۲ زنده (+۲۹۲٪)؛ ۳X+ به‌خاطر سایز all-in می‌میرد |
| E006 | آیا سایزینگ کسری/نوسان-هدف نجات می‌دهد؟ | **بله** — همهٔ اهرم‌ها زنده، افت حداکثر −۲۳٪ تا −۳۶٪، مقاوم به کارمزد ۲× |
| E007 | آیا لبه واقعی است؟ (تقسیم IS/OOS) | **رد شد** — لبه فقط گاوی ۲۰۲۰–۲۱ بود (OOS −۲٪ vs بورس‌اند‌هولد +۸۳٪) |
| E008 | فیلتر کیفیت روند (ER) کمک می‌کند؟ | **بله** — OOS +۲۰/۸٪ (نمونه کم) |
| E009 | پرمیوم تتر/تومان سیگنال است؟ | **بله** — z<−۲ → بازده ۷روزهٔ پیشرو +۲/۸٪ OOS (t=2.85) |
| E010 | وتوی پرمیوم روی ورود اثر دارد؟ | خنثی — به‌عنوان پایش ریسک نگه داشته شد |
| E011 | تجمیع ۹ دارایی بار شواهد می‌سازد؟ | **PASS ۶/۶** — پرتفوی +۱۴/۶٪، ۸۴ معامله، انتظاری +۲۴/۶٪، مقاوم به کارمزد ۲× |
| E012 | تیم قرمز: آیا پاس می‌ماند؟ | **شکست (۴/۵)** — لبه front-loaded بود: نیمهٔ دوم OOS −۶/۵٪ → تنزل |
| E013/E014 | عیب از خروج است یا رژیم؟ | خروج نه؛ **فیلتر SMA200 ضرر خرسی ۲۰۲۲ را ۵ برابر کم کرد** (−۱۶/۳→−۳/۰٪، انتظاری +۲۹/۱٪) — کاندید طبق قاعدهٔ از-قبل-اعلام‌شده پارک شد |
| E015 | بستر paper زنده؟ | **بله** — حساب ۲۰۰$، دفترچهٔ SQLite، کرون روزانه ۴:۳۰ |
| E016 | تحلیلگر AI در حلقه؟ | **بله** — ۹/۹ تحلیل فارسی معتبر روی دیتای زنده؛ بازار درست «نزولی/رنج» خوانده شد |

**۳۲ تست واحد سبز** — حسابداری وثیقه/کارمزد، ضد-توهم موتور، سایزینگ، فرمول‌های لیکویید، دوام پس از لیکویید، صفحات API.

### فاز ۴ — سیستم زندهٔ فعلی
- **حساب آزمایشی ۲۰۰$** با مدل کارمزد واقعی والکس (فعال‌سازی، تمدیدهای ۴ساعته، لیکویید)
- **چرخهٔ خودکار روزانه ۴:۳۰** + دکمهٔ «اجرای الان» در داشبورد
- **تحلیلگر AI** (مدل `claude-haiku-5-5` از endpoint شما): هر روز برای ۹ دارایی نظر ساختاریافته می‌دهد — گرایش، اطمینان، سطوح حمایت/مقاومت، خلاصهٔ فارسی
- **داشبورد فارسی v2** ([127.0.0.1:8787](http://127.0.0.1:8787)): قیمت‌های زندهٔ ۱۰ بازار، منحنی حساب، موقعیت‌های باز با سود/زیان لحظه‌ای و فاصلهٔ لیکویید، آمار جداگانهٔ «قانون vs AI»، دکمه‌های توقف/ادامه

## ۳. قواعد تصمیم‌گیری فعلی (قرارداد نامتغیر)

1. **ورود قانونی:** شکست کانال دونچین ۲۰روزه + ER≥0/30 (روند تمیز) + قیمت بالای SMA200 (رژیم) — با اهرم ۳، وثیقه ۲۰٪ سرپر (نوسان-هدف ۲٪/ATR)، حداکثر ۳ موقعیت
2. **تحلیلگر AI می‌تواند:** ورود قانونی را وتو کند، سایز را کوچک کند، یا با اطمینان ≥۷۰٪ یک ورود مستقل کوچک (سقف ۱۰٪ سرپر، یک اسلات) با برچسب 🤖 بگیرد
3. **AI هرگز نمی‌تواند:** اهرم را بالا ببرد، سقف ریسک را بشکند، یا **جلوی خروج/لیکویید را بگیرد** — خروج همیشه قانون قطعی است
4. **قطعیِ شبکه:** اگر مدل قطع شود، سیستم با نظر خنثی ادامه می‌دهد (تست‌شده)
5. **داده‌ها:** فقط دیتای لایو والکس؛ هیچ عدد ساختگی در هیچ حلقه‌ای

## ۴. قفل‌ها و قراردادهای امنیتی

## ۵. کارهای باقی‌مانده (نقشهٔ راه پیش‌رو)

### بلافاصله (نیازمند ورودی مالک)
| # | کار | چه چیزی لازم دارد | وضعیت |
|---|---|---|---|
| 1 | اتصال تلگرام | ساخت بات با @BotFather → فایل `telegram.json` | منتظر مالک |
| 2 | توکن داشبورد (دسترسی موبایل) | فایل `dashboard_token.txt` با رمز | اختیاری |
| 3 | مهاجرت به سرور | سرور ضعیف کافی است: ۱ هسته/۱GB/۱۰GB — ترجیحاً خارج از ایران برای تلگرام؛ `git clone + uv sync + paper serve` + crontab | منتظر تصمیم |
| 4 | کلید API والکس | فقط-معامله/بدون برداشت/IP محدود → اولین کار: تأیید تیر کارمزد حساب شما | منتظر مالک |

### کوتاه‌مدت (سیستم خودش انجام می‌دهد)
- چرخهٔ روزانهٔ paper و انباشت معاملات؛ امتیازدهی جداگانهٔ عملکرد «قانون» در برابر «AI»
- گزارش هفتگی مقایسه‌ای: انتظارات بک‌تست vs واقعیت paper (انحراف کارمزد/اسپرد/اجرای)
- پایش پرمیوم تتر و ثبت رژیم بازار در هر چرخه

### میان‌مدت (بعد از ۸ هفته paper)
- **دوزیرهٔ شواهد:** آمار کامل paper، تحلیل شکست‌ها، ضعف‌های باقی‌مانده، سقف‌های ریسک پیشنهادی
- ماژول معاملهٔ واقعی (idempotent با clientOrderId، reconcile بعد از 5xx، fail-closed) — **کد می‌شود ولی قفل می‌ماند تا تأیید شما**
- موتور ریسک پرتفوی سطح-زنده (سقف هم‌زمانی، خوشه‌بندی همبستگی)
- **درِ تأیید نهایی مالک** → پایلوت پول واقعی با سقف کم (پیشنهاد: ۵–۱۰٪ سرمایهٔ هدف)

### بلندمدت (اختیاری)
- فاز ML (مدل‌های تقویت سیگنال) فقط اگر قواعد فعلی کفایت نکنند
- شورت‌گذاری تحت فیلتر رژیم، دارایی‌های بیشتر، جمع‌وجوری زیرساخت
- ایجنت‌های تحقیق مستقل ۲۴/۷ (نیازمند API مدل جدا — فقط برای تحقیق، هرگز برای اجرا)

## ۶. راهنمای عملی (دستورها)

```bash
uv run pytest -q                            # تست‌ها (۳۲ سبز)
uv run python -m marketmind.cli paper run     # یک چرخهٔ معاملهٔ آزمایشی (قانون+AI)
uv run python -m marketmind.cli paper status  # وضعیت حساب/موقعیت‌ها
uv run python -m marketmind.cli paper serve   # داشبورد (پورت 8787)
uv run python -m marketmind.cli paper notify-test  # تست تلگرام
uv run python -m marketmind.cli backfill --all # به‌روزرسانی تاریخچه
uv run python -m marketmind.cli audit          # ممیزی کیفیت داده
uv run python -m marketmind.cli costreport     # جدول‌های سربه‌سر کارمزد
uv run python -m marketmind.cli validate --strategy donchian_er   # اعتبارسنجی IS/OOS
uv run python -m marketmind.cli redteam        # حملات تیم قرمز
uv run python -m marketmind.cli exitstudy      # مطالعهٔ خروج (فقط IS)
```

ساختار کلیدی:
```
src/marketmind/
  wallex/client.py     کلاینت عمومی والکس
  data/                دانلود، کیفیت، ذخیره (parquet)
  analytics/           کارمزد، پرمیوم تتر، تیم قرمز
  backtest/            موتورها (ساده/مارجین/سایزینگ)، استراتژی‌ها، اعتبارسنجی
  paper/               حساب آزمایشی (state)، چرخهٔ ترکیبی (runner)، تحلیلگر AI
  webapp.py            داشبورد v2
  llm.py, notify.py    مدل زبانی، تلگرام
docs/                  برنامه، دفترچهٔ پژوهش، گزارش‌ها، همین سند
data/secrets/          اسرار (gitignored)
```

## ۷. درس‌های بزرگ مسیر (چرا این سیستم قابل‌اعتماد شد)

1. **کارمزد، نه سیگنال، اولین قاتل بود** — تا اقتصاد واقعی را اندازه نگرفتیم، همه‌چیز فانتزی بود
2. **سایزینگ، نه جهت، دومی بود** — استراتژی درست با سایز all-in می‌میرد
3. **بازار گاوی، بهترین دروغ‌گوست** — فقط تقسیم IS/OOS حقیقت را گفت؛ تیم قرمز آن را دوبرابر کرد
4. **فیلتر رژیم (SMA200) بیشترین ارزش را دارد** — حذف معاملاتِ رژیم خرسی
5. **پرمیوم تتر سیگنال واقعی والکس است** — چیزی که هیچ صرافی دیگری ندارد
6. **قاعده را قبل از دیدن نتیجه اعلام کن** — وگرنه دروازه را بعد از گل جابه‌جا می‌کنی
7. **پنجرهٔ تست سوخته سوخته است** — از این به بعد فقط آینده قضاوت می‌کند
